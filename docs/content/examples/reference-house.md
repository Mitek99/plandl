![Schematic PlanDL conversion of the FH-114M reference house](../reference-house.svg)

This is a schematic conversion of the [FH-114M reference floor plan](https://full-houses.ru/media/images/projects/proekt-fh-114m-mode/mode-pryamoj-l.webp). It preserves the 11.875 m square grid envelope and the arrangement of bedrooms, bathrooms, laundry, hall, wardrobe, and combined living/kitchen space.

The raster image does not provide exact partition dimensions, so grid lines and compiler-inferred areas are approximate rather than a dimension-exact reconstruction. The example demonstrates compound rooms, bearing lines, windows, inner doors with inferred counterparts, and furniture.

The same definition is editable in the [front-page playground](../../#try-plandl). The complete source is available in the repository at `examples/reference-house.plandl`.
